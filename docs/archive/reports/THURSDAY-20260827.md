# ROLLBACK

**You are pre-authorised. If you decide to roll back, roll back.**

Roll back for exactly three things: **step 18 says `development`**, **step 19
returns 200**, or **step 23's stranger check shows a driven date working without
a key**. All three mean unpublished material is public. Nothing else in this
document is a rollback.

### R1 — see what is deployed

```powershell
npx wrangler versions list
```

### R2 — the fast path, tonight

```powershell
npx wrangler rollback
```

- **Cost:** seconds. Reverts the Worker only.
- **Cannot undo:** anything already written to the database, and it leaves
  `docs/DEPLOYED.md` describing a deploy that is no longer live. That is
  expected; the morning fixes it. **If you committed step 15, the morning has
  something to read. If you skipped it, it does not.**
- Confirm it worked by re-running step 16. `public, max-age=0` means the old
  worker is back.

the only path that leaves the tree and the live site agreeing. **Do not attempt
