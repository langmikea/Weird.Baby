## 5 · TWO DEFECTS IN THE LANDER, FOUND BY RUNNING THIS ROUND'S OWN PROOF

**A no-op `record:land --write` now REFUSES, and the refusal is correct.**
Guard 8 fires because the source has been hand-edited since the draft was
saved — its clock, not its content. **Nothing was written and the source is
byte-identical.** That is the expected shape of this work: each entry-emptying
commit makes the draft clock-stale, and a save from the day editor restamps it.
**Mike will meet this and it is not a defect.**

**BUT THE REFUSAL NAMES A PARAGRAPH THAT DID NOT CHANGE.** It reports:

```
Record 004 — 1 difference(s)
    section 2, paragraph 2:
      tree  {"pre":"    ROOT\n     /(many pwd protected folders)…"}
      draft {"pre":"    ROOT\n     /(many pwd protected folders)…"}
```

**Both sides are byte-identical** — measured: `JSON.stringify` equal, `pre`
equal, 215 bytes each. The cause is
`tools/dictation/emit-record-entries.mjs:747`:

```js
if (ab[j] !== bb[j])
```

**A REFERENCE COMPARISON ON A BODY ITEM.** It is right for a string and always
false for a `{pre}` object, so **every listing is reported as changed, on every
stale-draft refusal, forever.** It causes no wrong refusal — only a line that
sends somebody hunting for an edit nobody made.

**IT IS THE EXACT PATTERN THE ROUND-TRIP REPAIR ALREADY FIXED ONCE**, in
`record-edit.mjs`: `indexOf(c.after)` → `findIndex(p => textOf(p) === …)`. That
repair taught one file and this line was missed. The fix is `textOf(ab[j]) !==
textOf(bb[j])`.

**AND THE REFUSAL POINTS AT THE RETIRED EDITOR.** It says *"Open the editor
(`npm run record`)"* — the surface Mike ruled dies when Piece 4 ships. It should
say `npm run day:serve`.

**BOTH ARE FLAGGED AND NOT FIXED.** The lander is a `[MIKE]` command; changing
its behaviour deserves its own round and its own proof, and this commit is
scoped to one Record.
