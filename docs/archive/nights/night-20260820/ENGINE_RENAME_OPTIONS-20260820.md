## FIRST: TWO FACTS THAT NARROW THE FIELD

**Neither is an opinion, and one of them bears directly on the option you
suggested.**

### 1 · A YEAR IS ALREADY A COLUMN, so it cannot also be the name

Appendix C's table, from the manual generator:

```
("T", "C-1", "ENGINES FITTED AS STANDARD",
      ["ENGINE", "COMPILE DATE", "PRESENTATION"], 34)
```

**`ENGINE` and `COMPILE DATE` are two separate columns.** Naming the engine
`1945` would print the same fact twice in one row — and would leave the ENGINE
column carrying no identity at all. **The date column is already doing the
dating.**

### 2 · AND THE YEAR ITSELF IS CONTESTED — 1945 or 1946

If you want a year anyway, this has to be ruled first. The corpus says both, in
one document:

> `SPEC_INVENTORY` §D.4 — *"Preloaded answer engines with compile dates:
> **MGK-NIAC (1945**, original M8B responses only)…"*
>
> `SPEC_INVENTORY` §D.8 — *"**NIAC = the pure 1946 M8B twenty**; others
> voice-skinned."*

**1945 is the compile date; 1946 is the year the answer set belongs to** — and
1946 is the mothball year *and* the year the real Magic 8 Ball shipped, which is
the Carter/Bookman egg. A year-name has to pick one and would spend the other.

**Recorded as a new conflict either way** — it is in the catalogue now.

## THE THREE OPTIONS

**Constraint they all meet:** the front glass is **21 characters** on the system
face, and the label is drawn as `> ` + label + ` <`, so **17 characters is the
ceiling** and short is better. All three fit with room.

### OPTION A · `MK.I`

**The form is on the glass already.** The machine prints `MGK-AUX MK.II ROM
FACTORY` in the F/T dance — a mark number, carried verbatim from your own dance
lines and ruled to stand as period furniture (FT6).

| | |
|---|---|
| **Reads as** | a revision. `MK.I → v2.0 → 65` is a progression a reader gets without being told, which is what the Evolution Law wants the engine list to feel like. |
| **In Appendix C** | `MK.I · 1945 · …` — identity and date doing different jobs. |
| **Cost** | one string. |
| **What it risks** | **`MK.II` is the AUX's ROM — the top machine's BIOS, a different subsystem.** Two mark numbers on one instrument could read as one series when they are not. And `MK.I` itself is not attested; it is the attested form with a different numeral. |

### OPTION B · `TYPE 1`

**The form is on the nameplate.** `ABEAL · FEED CONTROL · MODEL NO. TYPE 8p` —
a TYPE designation is already how this house designates a thing.

| | |
|---|---|
| **Reads as** | a catalogue designation — flat, period, no story attached. |
| **In Appendix C** | `TYPE 1 / TYPE 2 / TYPE 3` against `1945 / 1946 / 1965`. The engine column becomes a clean ordinal series. |
| **Cost** | one string. |
| **What it risks** | **`TYPE 8p` designates the MACHINE.** Using TYPE for engines as well spreads one designation word across two kinds of object — which is the same shape as the collision being fixed, one level down. |

### OPTION C · `ROM 1`

**The form is on the glass twice** — `MGK-AUX MK.II ROM FACTORY` and
`FACTORY ROM ON FILE`.

| | |
|---|---|
| **Reads as** | what the thing actually is. An answer engine is a fixed, read-only answer set; ROM is the period-correct noun for exactly that, and the machine already says the word. |
| **In Appendix C** | `ROM 1 · 1945 · …`. |
| **Cost** | one string. |
| **What it risks** | the word is currently the AUX's, same as A. **Lower risk than A** because `ROM` is a noun for a class of thing rather than a serial in a series — two ROMs on one machine is ordinary, two MK numbers is a claim. |

## THE ONE OPS CONSIDERED AND IS RECOMMENDING AGAINST

### `M8B`

**It is the most attested option of all** — the firmware calls this exact data
`M8B_AnswerTable`, `M8B_ID`, `M8B_Answers_ParametersTable` throughout, and the
docs call it *"the pure 1946 M8B twenty"*. It names the CONTENT rather than the
machine, which is precisely the distinction you are drawing.

**Two reasons Ops is flagging against it rather than offering it:**

1. **It has never been on the glass.** `M8B` is source code and Ops vocabulary.
   Appendix G does not carry it. Putting it on a menu row makes an OPS
   abbreviation visitor-facing, which is the register split Doctrine 18 exists
   to police.
2. **`M8B` is one expansion away from "Magic 8 Ball"**, and Carter Bookman is a
   load-bearing egg. Printing it on the first screen a visitor reaches spends
   the egg for a naming convenience.

**Offered as information, not as a fourth option.** If you want it, it is one
string like the others.
