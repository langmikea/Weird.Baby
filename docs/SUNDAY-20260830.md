### 18 — the held door is shut

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" https://weird.baby/held/robots/manual/page-07.png
```

- **RIGHT:** `404`
- **NOT RIGHT:** `200` → **STOP and roll back now.** Same reason as 17.

**WHAT THIS PROVES AND WHAT IT DOES NOT — read it once, it changes nothing you
type.** The worker refuses `/held/*` **by prefix, before it looks for a file**
(`src/worker.js`, the `STAGE_DIRS` branch). So a `404` proves three things at
once — the request reached **this** worker first for that prefix, the built
worker's stage is **launch**, and the door refused a request with no key — and a
`200` means one of those three failed, which is exactly the leak this step
exists to catch. **What it cannot prove is that anything is behind that
address.** A path with no file answers the same 404 from the same line, so this
step tells you the door is shut but not that it is shut *on something*.
**Step 19 closes that half**, with the key, at the same address. If you are
short of time tonight, 18 alone is still the rollback trigger — 19's half tells
you whether to trust 18 next time.
