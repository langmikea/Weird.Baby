The Record →

write it in the Record itself

The museum’s own page, drawn by the museum’s own components, with every part of it editable where it sits — the headline, the index line, the lead, every section heading and every paragraph, the tombstone. It saves as you type, and one button hands the whole volume back to Ops.

Anything you write inside { curly braces } is a note to Ops rather than story. It stays in your copy, Ops acts on it, and the launch gate refuses to ship one. The two-column worksheet is retired; everything it asked is asked here, in the entry.

The in-story spec sheet

the thing to author from

Every piece of story-generated technical data about both machines, set as a period one-sheet. Marked asserted, implied, contradicted or absent; where two sources disagree, both readings print and the conflict is named.
