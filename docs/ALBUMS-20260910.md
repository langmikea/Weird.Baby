# THE ALBUMS — the robots wing at 50,000 feet, ruled 2026-09-10

Mike: "Each VIIIp model needs to have its own page. All of its photos, all
of its artifacts, documents, capabilities. Each one would be an album on
the robot page."

**The shelf.** The wing's front page is a shelf: the machines side by side,
one frame each, a name and a line. Pick one up and you are in its album.

**An album is one template, filled with data** (same except data):

| section | holds | source |
|---|---|---|
| the cover | the hero photograph, the name, the serial, one sentence of what it is for | manifest, unit registry |
| the plates | its photographs as evidence prints: closed, open, back, under; case; cable; box with its copy | the tray set, by manifest |
| the kit | the artifacts around it, each a print and a line | the tray set |
| the papers | its documents, readable: box copy, ads, the manual pages that concern it, the notebook | manifest, manual |
| what it does | capabilities as a plain list: engines, games, personas, settings; each line opens the shared feature page | the catalogue, the twin |
| the record | where it was found, what state, what the catalogue said; two paragraphs; the only story on the page | Ops writes, Mike rules |
| the door | run it in the twin; and, when the day comes, the line about having one | the twin |

**Outside the albums,** shared by every model: the feature pages (a game is
a game on every unit), the manual, the prologue. Albums link into them and
never repeat them.

**Ruled Q1 (C): an album is a unit and its character, paired, named for the
character**, because that is how the photographs already fall: the
Everyman (the Everyday unit), the Gambler, the CEO, the Informer.

**How it grows.** A new album is filled from the manifest and the catalogue
in an afternoon; a new photograph lands in a plate; a new artifact in the
kit. The daily reel points at the album or feature page of the day.
