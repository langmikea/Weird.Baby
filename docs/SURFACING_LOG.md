# THE SURFACING LOG

One line per run of `npm run surfacing -- --log`. It exists so the numbers
become a TREND rather than a reading: a wing whose spendable count only ever
goes up is building and not showing, and that sentence cannot be said by a
report taken once.

**Nothing here is a target.** An unshown thing is inventory, not a defect —
the museum is deliberately metered. What this catches is the shelf growing
two packets running with nothing coming off it.

Written by `tools/surfacing.mjs`. Do not hand-edit: a measurement somebody
adjusted is not a measurement.
