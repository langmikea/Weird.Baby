The boot's reason

A range to point at. Rough, on stand-in words. 2026-09-18. Nothing here is built.

  • You ruled: the machine arrives awake. The boot is for somebody who chooses it.
  • You said the chosen boot wants three things: a reason in the manual, an Easter egg, and maybe it is how you make the unit yours.
  • Below: three reasons (A, B, C), each as the manual's sentence and the glasses a visitor would see. Then three places unit 0.4 could hide (1, 2, 3).
  • A glass with a black border shows words the machine says today. A glass with a brown border is new, and its words are stand-ins for your pen.

What a visitor can already do today

  • Switch the machine off and on at the POWER control. A short boot plays and ends on SYSTEM OK.
  • Open the Welcome message and click. The whole install replays with SANDBOX in the corner. Nothing on the unit changes.
  • Type a name into Settings, User, Name. The machine keeps it in the visitor's browser.
  • None of these has a reason written anywhere. The manual is offline.

The reason: three rough examples

AThe remedy: "switch it off and on again"

the manual would say (stand-in words)
5-3. If the instrument answers strangely, switch it off at the rear, count ten, and switch it on. It will examine itself and report.
what the visitor sees

Flips POWER off, then on.

USER RECORD - ON FILE

The machine checks itself.

The egg. One boot in a few, the check finds something.

Back to the menu, awake.

SYSTEM OK

BThe delivery: new things arrive by restart

the manual would say (stand-in words)
7-2. New material reaches the instrument by line. When a message says material is waiting, restart the instrument to receive it.
what the visitor sees

Comes back on a later day. A message is waiting.

*NEW FEATURE ADDED click=restart scroll=exit

Clicks. The machine restarts and dials.

DIALING

DOWNLOADING (the chatter plays)

The menu has one more row than it had.

CONTENT INSTALLED
What comes backThat day's new program, seen arriving.

The catchA stranger from a reel must find the day's program already there (no dead ends). So this only plays for somebody returning, and the program is there whether they restart or not.

CMaking it yours: the personality download

the manual would say (stand-in words)
2-4. The instrument reaches you with no personality on file. To give it one, perform the personality download (Settings, User, Personality). The instrument restarts, and asks you one question.
what the visitor sees

Settings, User, Personality. Only the characters released so far are listed.

PERSONALITY [ THE GAMBLER ] scroll = change click = choose

Clicks. The machine restarts. The long first run plays.

FRESH INSTALLATION DETERMINED

The machine stops and asks its one question.

EXTRA CONTENT IS AVAILABLE [ DOWNLOAD NOW ] scroll = change click = choose

It wakes as that character. Next visit it arrives awake as theirs.

PERSONALITY - ON FILE SYSTEM OK
What comes backThe machine answers as the Gambler (his answers, his lean). The first-run messages arrive. It is still theirs next visit.
What Ops buildsThe most of the three. The personality row, each character's answers as that character appears, and the browser remembering the choice.
Makes it yours?Yes. This is the canon's own words: units ship generic, the customer performs the personality download.
Already ruledThe first run is longer and shows things once. The download happens whenever the owner likes. An owner of a numbered unit enters their code at the download.

These are not either-or. A can stand on day 2 with nothing else built. C is where "make the unit yours" lives.

Where unit 0.4 could hide: three rough places

1In what the chosen boot gives back

During any chosen boot, one line of the self-check, for one beat.

UNIT 0.4 REGISTRY OK

Only somebody who boots ever sees it. It goes by in about a second.
