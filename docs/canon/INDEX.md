# THE CANON — index

**One catalogue of everything this world holds. Written so Ops can answer a
specific question fast, not so anybody reads it through.**

**IT RESOLVES NOTHING.** Every conflict is Mike's to rule. Where two accounts
disagree they are both recorded, with their sources, and neither is marked
likely. **A catalogue that quietly picked winners is worse than no catalogue,
because nobody can tell which entries were decided and which were found.**

## HOW THIS CATALOGUE IS BUILT
<a id="rules"></a>

**Read this before adding to it.**

### THE ONE RULE

> **OPS RESOLVES NOTHING.** Every conflict is Mike's to rule. If you find
> yourself deciding which of two accounts is true, **STOP and record both with
> their sources.**

### THE FOUR FIELDS EVERY ENTRY CARRIES

| field | values |
|---|---|
| **What it means** | as attested. **Where the corpus names a thing and never says what it is, the row says so and stops.** |
| **Source** | file and, where it matters, line |
| **Register** | **`STORY`** — the machine or its documents say it · **`OPS`** — we say it about the machine and it has never been on the glass or on the page. **Doctrine 18 turns on that difference and the two must never be mixed into one appendix.** |
| **Publication** | **`PUB`** / **`SCHEDULED`** / unmarked — see [09-PUBLISHED](09-PUBLISHED.md#the-three-states) |

Plus, where it applies: **contested** (`K-nn`) and **absent** (`H-nn`).

### THE THREE RULES HELD THROUGHOUT

1. **NO TERM IS INVENTED.** Every row is attested and the row names where.
2. **NO CONFLICT IS RESOLVED.** No account is marked likely, preferred or better
   sourced. Where a document itself claims priority, that claim is quoted as a
   fact about the document — **it is not this catalogue agreeing with it.**
3. **A HOLE IS ABSENT, NOT ZERO.** *"The cell has no stated capacity"* is a hole;
   *"the cell has no capacity"* would be a fact, and a false one.
