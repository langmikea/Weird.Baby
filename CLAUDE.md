## What this repo is

weird.baby — Vite + React + React Router, served by a Cloudflare Worker (`src/worker.js`). The site is a tool inside Mike's ecosystem (his music, his robots, his foundation); it is not the product.

Routes (`src/App.jsx`): `/` lobby · `/wb` his music · `/wal` worth a listen · `/foundation` · `/shop` · `/booth` · `/robots` (opens itself on the clock, below) · `/hr` Hunter Root (HELD: password in every stage) · `/admin`. Anything else renders the lobby.

## The stage and the doors — read before touching a picture or a route

Two build stages via `WB_STAGE`: `development` (default, `npm run build`) shows everything placed; `launch` (`npm run build:launch`) holds what the Record has not delivered. **Two holds, and they never share a list:**

- `/assets/locked/` + `/locked/` — the PERMISSION hold (`/hr`). Refused in every stage without the `/admin` cookie (`HR_KEY` secret, no default).
- `/assets/held/` + `/held/` — the STAGE hold (the machines, the photographs). Opens in development.

Declared in `src/worker.js`. `src/lib/placement.js` is the only file in `src/` allowed to name a held prefix. `reveal/reachability.mjs` reads both back and `npm run reveal:check` fails if either loses an entry. A held path answers 404 from the worker; a merely missing path falls through to the shell with a 200.

## The clock

`RECORD_EPOCH` lives in one place, `src/data/artists/record-epoch.js`. Records post at 17:00 America/New_York (`reveal/record-clock.mjs`), read at request time, not build time. The robots wing opens itself at the first Record; nobody runs anything on the day.

Records are `src/data/artists/robots-record.js`, generated by `npm run record:land` from Mike's draft in `docs/dictation-20260807/`. **That folder is Mike's writing surface.** Do not hand-edit it, tidy it, restore it, or run `record:land` or `day:proof` while he is writing.
